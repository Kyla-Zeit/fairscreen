# Answer analysis

M10 implements deterministic, question-aware practice coaching over a reviewed
transcript. The analyzer accepts the interview question, reviewed transcript,
locale, timing/audio observations, and approved practice context. It does not
accept `VideoMetrics`; changing camera conditions cannot change answer-content
feedback.

Outputs include an overall takeaway, answer summary, evidence-linked categories,
strengths, improvements, a grounded stronger-answer framework, follow-up
questions, delivery observations, and a next action. Insufficient or nonsense
content receives an explicit insufficient-content result without invented
praise or résumé experience. This is practice feedback, never a hiring score,
rank, recommendation, personality inference, or suitability assessment.
